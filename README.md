# QuickChat

A console-based chat application built in Java for PROG5121 (Programming 1A).

## Features
- Part 1: User registration (username, password, South African cell number) and login
- Part 2: Sending, discarding and storing messages, with message IDs, hashes and JSON storage
- PoE: Message arrays, stored message search, delete by hash, longest message and report

## Tech
Java 21, Maven, JUnit 5, Gson, GitHub Actions
